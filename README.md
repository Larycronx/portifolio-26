# ✠ Larycronx — Portfólio

**Interfaces para ideias que merecem ganhar forma.**

Portfólio pessoal de **Larissa Francisco**, desenvolvedora criativa que transita entre lógica e narrativa — construindo interfaces, sistemas e experiências digitais com personalidade.

🔗 **Live:** [larycronx-dev.netlify.app](https://larycronx-dev.netlify.app/)

---

## 🐾 Sobre

> "Meu trabalho nasce do encontro entre estrutura e narrativa: um banco de dados precisa contar uma história com clareza, e uma interface pode fazer uma ideia complexa parecer simples."

Este site reúne projetos, experimentos e estudos em desenvolvimento web, modelagem de dados e ferramentas para mundos digitais — do código ao worldbuilding.

## 📁 Estrutura do projeto

```
portifolio-26/
├── index.html          # página inicial — sobre, projetos, contato
├── personagens.html     # galeria de personagens de RPG
├── rpg.html              # portal de hobbies / universo de RPG
├── styles.css            # estilos globais do site
├── Fonte/                # fontes tipográficas usadas no projeto
├── assets/                # imagens e ilustrações (ex: mascote Guaxi)
├── personagens/            # fichas e conteúdo dos personagens
└── som-das-seis/            # experiência audiovisual "Som das Seis"
```

## 🚀 Como rodar localmente

```bash
git clone https://github.com/Larycronx/portifolio-26.git
cd portifolio-26
# abra o index.html diretamente no navegador
# ou sirva com um servidor local:
npx serve .
```
